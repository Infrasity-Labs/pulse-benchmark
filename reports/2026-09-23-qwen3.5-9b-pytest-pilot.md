## 4. What's not included, and why

No resolved or unresolved percentage appears for either condition. That
figure requires running each patch through SWE-bench's own `FAIL_TO_PASS` /
`PASS_TO_PASS` test harness, which did not happen for this run, Direct or
Staged. Without it, "code change applied" is the honest ceiling of what these
numbers can claim for both conditions — it is **not** the same thing as a
task passing its hidden tests, and this run should not be compared directly
to the [`qwen3.8-flash` pilot](2026-09-18-swe-bench-lite-pilot.md), which
does report harness-graded resolved counts.
